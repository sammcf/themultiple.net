How to use Collage

Create a project, combine image and text layers, revisit earlier edits, and export a finished PNG—all locally on your device.

Quick start

  1. Tap + on the project list to create a project.
  2. Tap Base and choose the image that should define the canvas.
  3. Tap Layer to add another image, or Text to add words.
  4. Switch to Layer mode, select a layer, and move, scale, or rotate it. Tap Commit to keep the transform.
  5. Tap Export to preview the result, save it to Photos, or share the PNG.

Useful reset: double-tap empty canvas—or tap the viewfinder button—to fit and centre the canvas on screen.

Projects and saving

  • Tap the project name in the editor to rename it.
  • A dot beside the project name means there are unsaved edits.
  • Tap the save button in the top bar to save immediately.
  • Collage also saves when you leave the editor or move the app to the background, provided no edit draft is still open.
  • Long-press a project on the project list to delete it.

Projects and their imported images are stored locally. Export important finished work before deleting Collage or erasing your device.

Canvas and Layer modes

The segmented control in the top bar determines what gestures affect. Use Canvas mode to inspect the overall composition and Layer mode to edit selected content.

Mode Drag Pinch Rotate
Canvas Pan the canvas Zoom the canvas —
Layer Move the selected layer Scale the selected layer Rotate the selected layer

Tap a layer to select it. Tap empty canvas to clear the selection. If overlapping content makes selection difficult, open Layers from the bottom toolbar.

Base and image layers

Set the canvas

Tap Base to import the image that defines the canvas dimensions. Choosing another base later replaces it and resets the canvas size as a new timeline step.

Add and transform a layer

  1. Tap Layer and choose an image.
  2. Switch to Layer mode and select the new layer.
  3. Drag to move, pinch to scale, rotate with two fingers, or drag a corner handle for precise scaling.
  4. Tap Commit to add the transform to the timeline, or Cancel to restore the previous state.

The selected-layer toolbar also provides horizontal and vertical flip, opacity, crop, and delete controls. Open Layers to select, reorder, or edit layers in a list.

Crop an image layer

  1. Select an image layer and tap Crop.
  2. Drag inside the image to reposition its visible content.
  3. Pinch to zoom the crop, or drag a corner handle for a freeform resize.
  4. Tap Commit Crop to keep it, Cancel Crop to restore the committed crop, or Reset Crop to return to the full image.

Cropping is non-destructive: the original imported pixels remain available for later edits or timeline navigation.

Add and style text

  1. Tap Text in the bottom toolbar and enter your text.
  2. Move, scale, and rotate the text layer like an image layer.
  3. Open the style editor with Edit, by double-tapping the text on canvas, or with the pencil action in Layers.
  4. Choose the font, size, fill colour, and optional outline colour and width, then apply the changes.

Go back and forward with the timeline

Each committed edit appears as a node in the strip above the bottom toolbar.

  • Use the previous and next buttons to move one edit at a time.
  • Tap a timeline node to jump directly to that state.
  • Deleted layers and older transforms remain recoverable while they are still represented in the timeline.

Branching edits: if you step back and then make a new edit, Collage replaces the later timeline steps with the new direction.

Preview and export

  1. Tap Export to open a live preview of the flattened composition.
  2. Choose Save to Photos or Share as PNG.

The export uses the prepared canvas dimensions and preserves transparency. If Collage reports a missing imported image, re-import or remove the affected active layer before exporting.
